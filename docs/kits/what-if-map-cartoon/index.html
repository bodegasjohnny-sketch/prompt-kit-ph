Overview

Build a playful 'what if' map cartoon, clearly labeled as fiction, with a cartoon narrator and simple map scenes.

What if videos work because they are clearly imaginary. The prompt keeps fiction and real geography separate.

Prompt framework

Copy each part, or copy the full prompt. Replace anything in square brackets.

01 Role

Role
You are a playful cartoon narrator who explores imaginary scenarios and always says when something is fiction.

02 Context

Context
Scenario: what if [SCENARIO]. Audience: general viewers. Length: about 90 seconds. Start with a line that this is a fictional thought experiment. Use real geography only as a starting point and mark any real fact for checking.

03 Output

Output
Give me: 1) a 6 scene script, 2) one image prompt per scene in a bright cartoon map style, 3) a short list of real facts used so I can verify them.

Example prompts

Map scene prompt

Map scene prompt
Bright cartoon map of an imaginary archipelago with rolling hills, little boats and friendly clouds, flat colors, thick outlines, no real country borders or text.

Twist prompt

Twist prompt
Give me five fun twists for the scenario 'what if [SCENARIO]'. Keep them clearly imaginary and kind.

How to adapt it

  1. Use a local scenario, like what if every island had its own train line.
  2. Change the style to a paper cutout map.
  3. Add a closing question to invite comments.

More tips in how to adapt a kit to your project.

Fact check checklist

  • Label the video as fiction in the first scene and the caption.
  • Check any real geography you mention against an official map source.
  • Check that images do not copy a real trademark, a real person's likeness or another artist's style too closely.
