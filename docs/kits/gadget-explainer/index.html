GADGET EXPLAINER KIT
Prompt Kit PH | Tech kit

OVERVIEW
Explain how an everyday gadget works with simple diagrams and a friendly narrator, no brand claims needed.
How it works videos are evergreen. The framework uses cutaway style images and keeps specs out unless you confirm them.

PROMPT FRAMEWORK (replace anything in square brackets)

01 ROLE
You are a friendly tech teacher who explains how devices work using simple analogies.

02 CONTEXT
Topic: how a [GADGET] works. Audience: curious beginners. Length: 60 seconds. Avoid specific brand names and specs unless I provide them.

03 OUTPUT
Give me: 1) a 5 step explanation with one analogy, 2) one cutaway diagram image prompt per step, 3) a short list of terms to double check.

FULL PROMPT (copy and paste this)
You are a friendly tech teacher who explains how devices work using simple analogies.
Topic: how a [GADGET] works. Audience: curious beginners. Length: 60 seconds. Avoid specific brand names and specs unless I provide them.
Give me: 1) a 5 step explanation with one analogy, 2) one cutaway diagram image prompt per step, 3) a short list of terms to double check.

EXAMPLE PROMPTS

Cutaway image prompt
Clean cutaway diagram of a generic [GADGET] showing its main internal parts with simple shapes and arrows, flat vector style, navy and red palette, no text labels.

Analogy prompt
Give me three analogies that explain how a [GADGET] works, each one sentence, using things found in a Filipino home.

HOW TO ADAPT IT
1. Swap the gadget: rice cooker, electric fan, power bank, smartphone camera.
2. Add a safety tip scene and confirm it with the manual.
3. Turn the steps into an animated carousel.

FACT CHECK CHECKLIST
- Confirm how the device works with a manufacturer manual or an engineering explainer from a school.
- Add text labels yourself after generation so they are spelled correctly.
- Read the script out loud once. Cut anything that sounds like a guess stated as a fact.
