How to Adapt a Creator Kit to Your Own Project

Turn any kit on this site into a prompt for your own topic, audience and format in a few simple steps.

1 min readUpdated 2026-11-04
On this page
  1. Start with the framework
  2. Swap the placeholders
  3. Change the audience and length
  4. Match your format
  5. Review and refine
  6. Try it

Start with the framework

Every kit has a Role, Context and Output block. Copy all three into a notes app before you change anything.

Swap the placeholders

Replace anything in square brackets, like [BREED NAME], with your own topic. Then read the prompt again to see if the role still fits.

Change the audience and length

A script for kids differs from a script for adults. Changing these two details often matters more than changing the topic.

Match your format

For Reels or Shorts ask for fewer scenes. For carousels ask for slide text instead of narration.

Review and refine

Run the prompt, check the facts with the kit's checklist, then ask the AI to fix only the parts you want changed.

Try it

Example prompt
Here is a prompt framework: [PASTE KIT PROMPT]. Rewrite it for my project: topic [TOPIC], audience [AUDIENCE], format [FORMAT], length [LENGTH]. Keep the fact check line.
