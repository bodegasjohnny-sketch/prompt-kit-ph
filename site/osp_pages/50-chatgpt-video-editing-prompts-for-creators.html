How these commands work

The slash commands below are shortcut names for the full prompts. They aren’t built-in ChatGPT commands. Upload your video, find the edit you want and use the full copy-and-paste prompt.

ChatGPT can analyse your footage and plan or direct the edit. Whether it can also make the edit and export a finished file depends on the ChatGPT tools and workflow you’re using.

How to use these prompts

  1. 01 Upload your video to ChatGPT Or point it at the folder with your footage if you are using Codex (below).
  2. 02 Pick the editing job you want below Each card says what the prompt does in one line.
  3. 03 Copy the full prompt Use the Copy prompt button. The slash command is just its name.
  4. 04 Give ChatGPT any extra context or assets it needs Your platform, the length you want, and any screenshots, comments or brand assets the prompt mentions.
  5. 05 Review the suggested edit before publishing Check the cuts, captions and anything it blurred or moved.

Tip: you can combine prompts. For example, use /hookcut, then /removefiller, then /dynamiccaptions to build a complete short-form edit.

Want the edit made, not just planned? Use Codex in the ChatGPT desktop app. Open the app, select Codex from the top-left menu, open the folder with your raw footage, then paste a prompt. Codex can work on the file and write a new one back out, which is why every prompt here ends with a named export: your original is never overwritten.

Tell it these up front and you will spend far less time re-exporting: your target platform, the aspect ratio, the target length, the editing style, whether it may remove content, and the filename you want back.

Hooks & Retention: 7 prompts

The first few seconds decide whether anyone watches the rest. These find the strongest opening, then keep people there.

/hookcut

01

Find the Strongest Spoken Hook

Open on the best line you actually said, not the first one you recorded.

Full promptCopy prompt

Analyse the full recording and find the strongest spoken opening: the single line or 5-10 second statement that would make someone stop scrolling.Prioritise lines that contain:

a surprising claim
a clear benefit
a strong opinion
a question the viewer wants answered
a promise the rest of the video keeps

Move that line to the very start, then restructure the following footage so the video still makes logical sense.
This is about the spoken hook. If the strongest opening is a visual result rather than something I said, tell me and suggest /proofcut instead.
Do not invent a hook that was never recorded.
Export as hook-cut.mp4.

Common questions


  • Are these official ChatGPT commands?
    No. The slash commands are shortcut names we use so each prompt is easy to find and remember. Copy the full prompt underneath: that is what does the work.

  • Does ChatGPT actually edit the video?
    ChatGPT can analyse your footage and plan or direct the edit. To have it work on the file and export a finished version, use Codex in the ChatGPT desktop app, which can open the folder on your machine and write a new file back out. What is possible depends on the tools you have.

  • Will it overwrite my original footage?
    Not with these prompts. Every one ends with a named export like clean-cut.mp4 or final-social-edit.mp4, so the edit lands beside your raw file rather than on top of it. Say it out loud as well for the first few runs.

  • Can I run more than one prompt on the same video?
    Yes, and most finished videos use three or four in a row. The prompt stacks above show some good combinations. Feed each export into the next prompt rather than going back to the raw file.

  • Can it add music?
    It can, but /musicbed tells it to say so rather than reach for copyrighted music it does not have the rights to. Supply your own licensed track if the result matters.

  • How long can the footage be?
    Longer recordings take longer to process, and very long files may need splitting. The repurposing prompts are written to pull short clips out of a long source, so start there rather than trying to edit an hour in one pass.
